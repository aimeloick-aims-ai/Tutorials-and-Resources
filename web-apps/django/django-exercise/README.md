# Django Exercise

Sanitized learning project consolidated from the former private `Django_Exercice` repository.

The original repository was an incomplete Django 4.2.4 exercise. Generated Python caches and the hard-coded development `SECRET_KEY` were intentionally excluded from this public copy. The original settings referenced `home` and `Blog` applications that were not present in the repository, so this folder is retained as framework-learning material rather than a runnable production application.
